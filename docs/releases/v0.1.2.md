# v0.1.2 — Broad Competency Calibration

Status: implementation, automated/scripted validation, and live fresh-Codex-chat acceptance passed.

## Behavior

Whole-area graph-theory calibration now defaults to a survey. It samples concepts without requiring prerequisite readiness, then targets follow-ups using saved direct evidence. A weak connectivity answer cannot terminate the whole survey. Focused calibration checks only a target and its prerequisite closure and retains useful-boundary stopping.

Coverage reports distinguish current and historical assessments, representative scope, skipped/deferred participation, capability outcomes, untested capabilities, remaining prompts, and uncertainty. Coverage does not promote competence. Evidence, projection rules, confidence thresholds, stable IDs, graph relationships, and the fourteen-question bank are unchanged.

Each block permits 1–14 response turns, default eight. Budget exhaustion pauses when informative work remains; explicit pause preserves an unanswered prompt. Continuation grants an additional bounded block and recovers saved answers. Explicit stop remains terminal. New calibration checkpoints use version 2; teaching and evidence remain version 1. Old unfinished calibrations upgrade only on their next checkpoint update; old ended sessions stay ended.

The [saved plan](v0.1.2-plan.md), [user guide](../user-guide.md#calibration), and [coverage policy](../architecture.md#calibration-selection-and-coverage) define scope and operation.

## Discoveries and limitations

The old boundary stop reproduced after connectivity and two terminology questions. It was selector behavior reinforced by the skill and guide, rather than a projection defect. A new historical-evidence test also exposed unnecessary explanation repeats; selection now prefers the missing representative capability when only one remains untested.

Final-turn self-report prompts are now consumed before a budget pause. Terminal sessions remain unchanged on repeated selection. Completion because the bank is exhausted is distinct from supported readiness, and no area-wide mastery flag is introduced.

The finite bank and conservative competence rules remain limitations. A survey can finish with unresolved concepts, and retained downstream understanding does not erase a foundational gap. The bundled skill validator's missing optional dependency is reported above; manual frontmatter/reference checks passed.
